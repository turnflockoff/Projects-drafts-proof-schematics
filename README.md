### Image publication scope

The project owner has explicitly requested publication of all original hardware photos and generated engineering illustrations. The image register distinguishes the 29 original hardware photographs from 13 generated concepts and provides a description and proof value for each filename. Actual binary image files are **not yet present** in this repository; the prepared ZIP archive is available in the ChatGPT conversation for transfer. Do not describe the binary images as published until the files are committed.

## Evidence handling

- Preserve original photos unmodified where possible.
- Keep generated illustrations separate from original evidence.
- Label conceptual renders as conceptual—not measured CAD, verified schematics, or manufacturing-ready designs.
- Leave dates blank when they cannot be established from reliable records.
