### Scope and distribution

The existing repository note says concept art is not to be distributed. Accordingly, generated concept artwork is withheld from this publication pending an explicit change to that restriction. Original evidence photographs and generated artwork are classified separately.

V-E0 is an independent research codename. No manufacturer affiliation, authorization, sponsorship, or endorsement is claimed. This documentation does not establish a verified pinout, decoded protocol, working replacement controller, or safe vehicle modification.

## Evidence handling

- Preserve original photos without alteration where possible.
- Keep generated illustrations separate from original evidence.
- Label conceptual renders as conceptual—not measured CAD, verified schematics, or manufacturing-ready designs.
- Leave work dates blank when they cannot be established from reliable records.
